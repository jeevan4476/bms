# Exception Package

This package contains custom exception classes and exception handlers.

## Purpose
- Define custom business exceptions
- Global exception handling with @ControllerAdvice
- Error response formatting

## Examples
- `ResourceNotFoundException.java` - Resource not found exception
- `BookingException.java` - Booking-related exceptions
- `GlobalExceptionHandler.java` - Global exception handler
- `ErrorResponse.java` - Standardized error response DTO
