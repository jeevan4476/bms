# Entity Package

This package contains JPA entities representing database tables.

## Purpose
- Define database schema through annotations
- Map Java objects to database tables
- Define relationships between entities

## Examples
- `User.java` - User entity
- `Movie.java` - Movie entity
- `Booking.java` - Booking entity
- `Show.java` - Show entity
- `Venue.java` - Venue entity
- `Seat.java` - Seat entity
