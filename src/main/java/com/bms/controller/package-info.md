# Controller Package

This package contains Spring MVC controllers that handle HTTP requests.

## Purpose
- Handle incoming HTTP requests
- Validate request data
- Call service layer methods
- Return views or JSON responses

## Sub-packages
- `admin/` - Admin-specific controllers
- `api/` - REST API controllers (if needed)

## Examples
- `HomeController.java` - Home page
- `MovieController.java` - Movie browsing and details
- `BookingController.java` - Booking flow
