# DTO Package

This package contains Data Transfer Objects for request/response handling.

## Purpose
- Transfer data between layers
- Request validation
- Response formatting
- Decouple internal entities from API contracts

## Sub-packages
- `request/` - Request DTOs
- `response/` - Response DTOs

## Examples
- `MovieDTO.java` - Movie data transfer object
- `BookingRequest.java` - Booking creation request
- `BookingResponse.java` - Booking confirmation response
